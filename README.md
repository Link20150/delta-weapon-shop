# 三角洲武器铺（微信小程序）

自用 + 朋友用的三角洲行动改枪码小程序。原生微信小程序 + 微信云开发，轻量无服务器。

> 当前仅支持 **烽火地带** 模式的改枪方案。

## 产品定位

**给不会改枪的新手用**：打开就能抄，便宜好用不折腾。

- 目标用户：完全不懂配件的新手，例如只用缴获枪、不想研究改枪的朋友
- 核心体验：三步拿到代码 → 复制 → 游戏内导入，方案以低预算、新手友好优先
- 不做的事：不堆专业术语、不追求满改教程、不做复杂社区

## 功能（两个页面）

- **推荐页（首页）**：每日推荐 5 套改枪（低预算/新手友好优先），可一键复制改枪码；预留今日密码位
- **枪库页**：三角洲行动全部 65 把枪，按 8 个分类排列（突击步枪/战斗步枪/冲锋枪/精确射手步枪/轻机枪/霰弹枪/狙击步枪/手枪），支持搜索；点进任意枪查看该枪全部改枪方案，每套方案可复制或看详情

1. 用**微信开发者工具**导入本目录（`D:\Desktop\codex\df`），AppID 已配置为 `wx001baccafe64b5c1`。
2. 云环境已开通：`cloud1-d2g7fzcmh7ede1075`。
3. 云函数部署：右键 `cloudfunctions` 下每个云函数 → 「上传并部署：云端安装依赖」。
4. 首次/更新数据时，在云开发控制台运行一次 `initData`，返回 `importedCodes: 78` 即成功。
5. 编译运行，真机预览可分享给朋友。
