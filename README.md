# 三角洲武器铺（微信小程序）

自用 + 朋友用的三角洲行动改枪码小程序。原生微信小程序 + 微信云开发，轻量无服务器。

> 当前仅支持 **烽火地带** 模式的改枪方案。

## 产品定位

**给不会改枪的新手用**：打开就能抄，便宜好用不折腾。

- 目标用户：完全不懂配件的新手，例如只用缴获枪、不想研究改枪的朋友
- 核心体验：三步拿到代码 → 复制 → 游戏内导入，方案以低预算、新手友好优先
- 不做的事：不堆专业术语、不追求满改教程、不做复杂社区

## 项目结构

```
df/
├── project.config.json      # 开发者工具项目配置
├── miniprogram/             # 小程序代码
│   ├── app.js               # 云开发初始化（需填 env）
│   ├── app.json             # 页面与 TabBar 配置
│   ├── pages/
│   │   ├── recommend/       # 推荐页（首页 Tab）
│   │   ├── arsenal/         # 枪库页（Tab）
│   │   ├── profile/         # 我的页（Tab）
│   │   ├── detail/          # 方案详情页
│   │   ├── quiz/            # 条件推荐问卷页
│   │   └── my-codes/        # 我的代码页
│   ├── data/sample-codes.js # 示例改枪码数据（框架演示用）
│   └── utils/util.js        # 复制/收藏等工具

```

## 快速开始

1. 用**微信开发者工具**导入本目录（`D:\Desktop\codex\df`）。
2. 在 `project.config.json` 中把 `appid` 换成你自己的小程序 AppID（当前为 `touristappid` 游客模式）。
3. 点击「云开发」开通云环境，把环境 ID 填到 `miniprogram/app.js` 的 `env` 字段。
4. 右键 `cloudfunctions` 下的每个云函数 → 「上传并部署：云端安装依赖」。
5. 部署后在云开发控制台运行一次 `initData`（或直接调用），示例数据会写入 `codes`、`daily` 集合。
6. 编译运行，真机预览可分享给朋友。

## 当前状态

- 框架已完成：3 个 Tab + 6 个页面 + 4 个云函数骨架
- 云函数未部署时，页面自动降级为本地示例数据，方便先看效果
- 云函数部署并初始化数据后，页面自动走云数据库，无需改代码
